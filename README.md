# Anime Chess: Multiverse War — playable download

Download **anime-chess-multiverse-war-online.zip** from this branch and extract it.

Requires Node.js 22.12 or newer. Open a terminal inside the extracted `AnimeChessMultiverseWar` folder and run:

```sh
npm ci
npm start
```

Open the local address printed by the server (port 3001). The archive includes the built game and complete source: Local PvP, Stockfish AI, and private online rooms.

For online play between different devices, run the server at a reachable LAN or public address. See `docs/ONLINE_MULTIPLAYER.md` in the ZIP for configuration and deployment instructions. Private rooms restore temporary browser disconnections; server restarts end rooms.

The exact requested roster is included. The 32 full-body GLB figurines are original stylized placeholders ready to replace with licensed detailed assets.
